# Public release checklist

Completed locally: source allowlist; new package metadata; executable synthetic demo; component tests; no original Git history copied.

Before public release:

- Confirm copyright and collaborator authorization; choose a license and preserve upstream notices.
- Review the included source and synthetic example output; do not describe this subset as the full paper artifact.
- Choose the GitHub owner and repository visibility. Use a new repository without copying the research workspace history.
- Validate supported Python/dependency versions on the intended platform; current dependencies are not locked or vulnerability-audited.

There is no configured remote and no automatic publishing workflow. Repository creation and pushing are separate actions.
